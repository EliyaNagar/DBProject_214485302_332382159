# הוראות הפעלה - שלב ה' (ממשק גרפי)

## 1. דרישות מקדימות
- Python 3.10+ (נבדק על 3.14) עם `tkinter` (מגיע מובנה עם פייתון).
- ספריית חיבור ל-PostgreSQL:
  ```bash
  pip install psycopg2-binary
  ```

## 2. הפעלה
מתוך תיקיית הפרויקט:
```bash
cd stageE
python mainApp.py
```

## 3. כניסה למערכת
| שדה | ערך |
|-----|-----|
| שם משתמש | `admin` |
| סיסמה | `1234` |

מסך הכניסה מאמת את הפרטים וגם בודק חיבור פעיל למסד הנתונים לפני המעבר לתפריט.

## 4. ניווט במערכת
לאחר ההתחברות נפתח התפריט הראשי עם שלושה מסכים:

1. **🗄️ ניהול נתונים (CRUD)** – בחירת טבלה (מתוך 14) וביצוע שליפה / הוספה / עדכון / מחיקה.
   - **עדכון:** הזן את שדה/שדות המפתח ולחץ "שמור" → המערכת תשלוף את הרשומה →
     ערוך את השדות הרצויים → "שמור" שוב.
   - מפתחות זרים מוצגים כשמות (תיבת בחירה), לא כמספרים.
2. **📊 דו"חות ושאילתות** – בחירה והרצה של שאילתות משלב ב'.
3. **⚙️ פעולות מתקדמות** – הפעלת פונקציות ופרוצדורות משלב ד' עם פרמטרים.

## 5. הערה על החיבור למסד הנתונים
פרטי החיבור מוגדרים ב-`DAL/database.py`. המערכת מתחברת ל-PostgreSQL
המתארח ב-Supabase. נדרש חיבור אינטרנט פעיל.
