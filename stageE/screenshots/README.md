- `03_crud_grid.png` – מסך CRUD עם הצגת שמות במקום מזהים
- `04_crud_update.png` – תהליך עדכון (הקשת מפתח → שליפת שדות)
- `05_reports.png` – מסך דו"חות עם תוצאות שאילתה
- `06_actions.png` – מסך פונקציות ופרוצדורות
